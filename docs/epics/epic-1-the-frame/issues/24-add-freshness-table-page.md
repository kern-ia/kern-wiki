# Add the freshness table page and the status section

## Summary

Deliverable 13, and the third mitigation for *the wiki contradicts the repos*: one page where a
reader sees, per page, which brick it documents, which version was verified and when. The table
itself is generated by [Issue 11](./11-add-generated-registries.md) — this issue is the page that
hosts it and the prose that makes it readable.

## Scope

- `en/status/freshness.md` — the generated freshness table between its markers, plus the prose
  around it: what a stamp asserts, what an absent stamp means, and what to do about a row that looks
  wrong.
- `en/status/_index.md` filled in: the three page states stated once and distinguishably — *not
  documented yet*, *verified against version X*, *possibly stale* — and which field carries each.
- **Placeholders appear in the table**, listed as *not documented yet* rather than as stale or
  blank, so the wiki's unwritten areas stay visible rather than absent.
- A statement that no automation ever writes a stamp, the staleness job included — a stamp means a
  human read the code.

## Out of scope

- **No staleness derivation and no weekly job** — epic 4. This page shows what pages claim; nothing
  here decides what has rotted. *Possibly stale* is defined here and computed there.
- **No transverse status across repos and no consolidated roadmap** — epic 4.
- **No hand-written table.** If a row is wrong, the fix is the page's front matter or the generator,
  never the table.
- No stamp edits to other pages from this PR.

## Acceptance criteria / Definition of done

- [ ] The table is generated, sits between the markers, and `gen --check` passes.
- [ ] Every page in the bundle appears, placeholders included and labelled *not documented yet*.
- [ ] The three page states are each defined once, and each maps to a named front matter field.
- [ ] The prose states that no automation writes a stamp.
- [ ] Editing prose outside the markers survives a regeneration byte-identical.
- [ ] `hugo` builds; `validate` passes; hard-wrapped at 100 columns.
