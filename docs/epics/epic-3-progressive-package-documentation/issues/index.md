# Issues — Epic 3: Progressive package documentation

Cut one brick at a time, as the epic expects. Issue 01 goes first and sets the depth pattern the
other brick pages follow; 02–04 are the remaining three bricks, independent of each other. 05
discharges the operational-traps criterion separately so it cannot be dropped when the brick pages
run long, 06 discharges the adoption criterion by doing it, and 07 is the slot for the fifth package.

Each brick page is one PR, because a content page is never split across two — which is why 01 and 02
are sized L and cannot be split by section.
