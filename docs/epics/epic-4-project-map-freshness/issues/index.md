# Issues — Epic 4: Project map & freshness

Numbered in dependency order. Issues 01–03 are the three status pages — the transverse view a
maintainer opens, and the epic's headline. 04–07 are the automation that keeps the rest of the wiki
honest: the weekly external link check, then the staleness job split into computation, publication
and the second freshness axis. 08 is last and discharges the epic's one acceptance criterion by
using the pages rather than asserting they work.

None of the status pages is generated — SPECS fixes the generated set at five surfaces, and a
transverse judgement is not derivable from front matter.
