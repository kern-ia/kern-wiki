# Kern wiki — planning bundle

Planning knowledge for the `kern-ia` ecosystem wiki: a self-contained documentation site for the
Kern bricks (`kern-link`, `Kern-Anon`, `Kern-Orch`, `Kern-UI`, and packages still arriving),
built as a frame that fills progressively and never asserts what hasn't been verified.

* [Scope](SCOPE.md) - the decided scope: problem, users, criteria, non-goals, five milestones
* [Scope decision ledger](/scope/index.md) - every scope decision, its options, recommendation and verdict
* [Technical specs](SPECS.md) - the decided stack and shape: Hugo + Hextra, an OKF bundle on GitHub Pages, truthfulness enforced by CI
* [Specs decision ledger](/specs/index.md) - every specs decision, its options, recommendation and verdict
* [Conventions](CONVENTIONS.md) - how this repository is written and reviewed: the personal baseline re-aimed at a repository whose product is prose
* [Conventions decision ledger](/conventions/index.md) - the deviations and gaps only; anything unlisted is settled by the baseline
* [Bundle history](/log.md) - what changed in this bundle, newest first
